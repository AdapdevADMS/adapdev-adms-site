The first public release of ADMS. The product has been in private trials
with a small cohort of sole traders, small businesses and law firms over
the preceding months; everything in those installations is now
generally available.

## New

- **Server API** built on .NET 9 and ASP.NET Core; supports SQL Server
  2019 and later, with a bundled SQLite option for single-user
  installations.
- **Desktop client** built on WPF and the Prism Framework; connects to
  the server API over HTTPS; supports Argon2id password hashing with
  JWT bearer sessions.
- **Office add-ins** for Word, Outlook, Excel and PowerPoint; installed
  by the desktop client installer.
- **ISecretProvider abstraction** with a default Windows DPAPI
  implementation. Enterprise customers can opt into the Azure Key Vault
  implementation at install time.
- **Authenticode-signed installers** for both server and desktop,
  signed by Adapdev Pty Ltd. SHA-256 checksums published alongside each
  download.

## Known limitations

- Mac and Linux desktop clients are not yet available.
- Automated backup to S3-compatible storage is on the roadmap for 1.1.
- Full-text search is English-language only in this release.

## Upgrade notes

Not applicable - this is the initial release.
